# Baseline

## Baseline Approach

The baseline represents a reasonable simple approach:

> Review the developer task and provide an implementation plan.

The baseline uses a single general-purpose AI response rather than the specialized multi-agent workflow.

## Baseline Prompt

```text
You are a software development assistant.

Review the following developer task and provide a practical implementation plan.

Identify:
- What the user wants
- Main requirements
- Technical considerations
- Implementation steps
- Potential edge cases

Do not invent requirements.

Developer task:

[TASK]
